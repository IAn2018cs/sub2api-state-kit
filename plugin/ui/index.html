总开关与动态代理

总开关和账号开关均开启时，该账号才会获取、使用票据。

本机 → 前置代理 → 动态代理 → 获取 STATE。能直接连接动态代理时留空；此设置只影响采集。支持 HTTP(S) / SOCKS5(H)。

可手动填写已有代理的完整地址。当前宿主插件接口不提供「代理管理」列表；容器中的 127.0.0.1 指向容器自身。

支持 HTTP、HTTPS、SOCKS5 和 SOCKS5H。地址中的 {random} 或 {sid} 在每次尝试时替换为随机会话值。请填写自己的代理，不在此处填写账号 Token。

关闭并保存后停止票据获取与注入；正常请求继续转发。

每次采集及复验通过同一代理会话访问 ipify 查询公网出口，只发送 IP 查询，不发送账号授权。另建连接时出口可能变化；查询失败不会阻止采集。
